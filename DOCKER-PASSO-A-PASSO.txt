PASSO A PASSO
1. Abra Docker Desktop no menu Iniciar e aguarde o mecanismo ficar pronto.
   Use Linux containers. Se pedir configuracao de WSL, siga a orientacao
   do instalador e envie qualquer erro antes de mudar outras configuracoes.
2. Abra PowerShell na pasta que contem artisan, Dockerfile e compose.yaml.
3. Confira:

   docker version
   docker compose version

Se docker nao for reconhecido, feche/reabra o terminal. Se persistir,
adicione somente para essa sessao:

   $env:Path += ";$env:LOCALAPPDATA\Programs\DockerDesktop\resources\bin"

4. Confira os arquivos e construa/inicie:

   docker compose config --quiet
   docker compose up -d --build

O primeiro build baixa imagens e instala dependencias; pode demorar.
Se a porta 8000 estiver ocupada pelo servidor PHP local, pare esse servidor
com Ctrl+C antes de iniciar o container.

5. Teste a conexao somente por leitura:

   docker compose exec app php artisan banco:verificar

6. Abra http://localhost:8000 para ver a pagina inicial do Laravel.
   Ainda nao existem telas de cadastros ou Vue.

OUTROS COMANDOS
Ver estado: docker compose ps
Ver erros: docker compose logs --tail=80 app
Parar: docker compose stop
Retomar: docker compose start
Depois de mudar Dockerfile ou dependencias: docker compose up -d --build

BANCO LOCAL
host.docker.internal aponta do container para o Windows no Docker Desktop.
O PostgreSQL precisa aceitar essa conexao. Pode ser necessario ajustar
listen_addresses, pg_hba.conf ou firewall; ainda nao foram modificados.
Se houver erro, envie a mensagem. Nao libere acesso para todos os enderecos.
Nao execute migrations para resolver erro de conexao.
